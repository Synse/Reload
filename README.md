Reload adds slash commands and a customizable keybind to reload your ui.

## Slash Commands

Use any of the following slash commands to reload your interface quickly:

*   `/rl`
*   `/reload`
*   `/reloadui`

## Key Bindings

🆕**New in v1.1.2:** set a keybinding to reload your ui at the press of a button. Great for AddOn development!
